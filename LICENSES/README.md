# Licence text stock

These are full licence texts kept for **copying into each addon**, not the licence of this
repository or of anything in it.

Addons are delivered individually — extracted with `git subtree` or copied into a customer's Odoo
addons path — so each addon carries its own `LICENSE.md` and its own `LICENSES/` copies of the texts
it must ship. A text that lives only here does not travel with the addon it licenses.

`scripts/check_licenses.py` checks placement per addon and never reads this directory. Once every
addon carries its own copies, keep this stock for convenience or delete it.

See [`../LICENSE.md`](../LICENSE.md) for what to copy where.
